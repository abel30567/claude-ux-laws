# Contributing

1. Fork, branch, keep changes focused.
2. The laws are public design knowledge — write-ups must be original,
   and any correction to a law's definition needs a source.
3. If you add a law (the reel lists Postel's law twice — a genuine
   twentieth distinct law is welcome), add it to `ux-laws.md`,
   `SKILL.md`, and the README table, and say where it comes from.
